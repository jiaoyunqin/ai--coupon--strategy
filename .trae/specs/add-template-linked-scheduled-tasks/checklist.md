# 验收清单

## 产品对象与入口

- [x] 工作台提供独立“定时任务”入口，页面主操作为“新建定时任务”。
- [x] “任务模版”和“定时任务”是相邻但职责独立的产品对象。
- [x] 进入定时任务不会错误打开任务模版库或策略灵感。
- [x] 离开定时任务时正确关闭抽屉和临时状态，不影响其他工作台页面。

## 管理首页

- [x] 首屏展示运行中、今日已触发、待处理、今日已推送四个核心指标。
- [x] 提供“任务列表 / 运行记录”页签。
- [x] 支持按名称搜索。
- [x] 支持按实时监控、每日推送筛选。
- [x] 支持按运行中、已暂停、待处理筛选。
- [x] 支持按活动筛选。
- [x] 默认优先展示待处理任务，再按最近触发时间排序。
- [x] 空结果时展示明确空态和可恢复筛选的操作。

## 任务列表与详情

- [x] 桌面任务列表展示任务、关联模版、活动范围、触发规则、最近结果、下次动作和管理操作。
- [x] 任务状态与单次运行结果使用不同字段和文案。
- [x] 点击任务可打开详情抽屉。
- [x] 详情首屏展示当前信号、规则摘要、关联模版、活动范围、投递位置和最近 5 条记录。
- [x] 完整参数、能力依赖和历史快照默认折叠。
- [x] 支持编辑、复制、启用和暂停。
- [x] 实时监控提供“立即检查”，每日推送提供“立即生成”。
- [x] 手动运行不改变下一次自动检查或推送时间。

## 两类触发方式

- [x] 创建流程第一步明确区分“实时监控”和“每日推送”。
- [x] 实时监控只展示指标/事件、关系、阈值、连续命中、检查频率和冷静期。
- [x] 每日推送只展示执行日、执行时间、时区和可选到期时间。
- [x] 公共字段包含名称、活动、按需波次、生效时间和模版变量映射。
- [x] 实时监控未命中时只更新最近检查，不持续制造无效运行记录。
- [x] 每日推送同一计划时间只生成一次运行记录。
- [x] 暂停期间不产生新运行记录，恢复后不补跑历史时间。

## 场景快速起草

- [x] 创建第一步提供预算消耗接近上限场景。
- [x] 创建第一步提供 GMV 目标达成偏离场景。
- [x] 创建第一步提供券档或渠道钱效异常场景。
- [x] 创建第一步提供竞对券档、折扣或张数变化场景。
- [x] 创建第一步提供每日预算消耗进度通知场景。
- [x] 每个场景均预选正确的触发方式、任务模版和默认规则。
- [x] 所有场景预填值均允许用户修改。

## 任务模版联动

- [x] 每个定时任务必须引用一个已启用任务模版。
- [x] 创建流程支持搜索并改选任务模版。
- [x] 选择模版后展示变量、产出和能力状态摘要。
- [x] 支持从定时任务创建流程新建任务模版。
- [x] 新模版保存后返回原定时任务草稿并自动绑定。
- [x] 已启用任务模版详情提供“创建定时任务”。
- [x] 新建任务模版保存结果提供“创建定时任务”。
- [x] 从模版进入创建流程时来源模版已预选。
- [x] 草稿或停用模版不能创建定时任务。
- [x] 模版详情展示被定时任务引用的数量，并可跳转到对应列表。
- [x] 模版后续变化不改写历史运行记录。
- [x] 定时任务可由用户确认应用新的模版内容。
- [x] 界面不展示 `Revision`、内部版本号或完整 Prompt。

## 新增内置任务模版

- [x] 任务模版库新增“预算消耗进度简报”。
- [x] 模版阶段为促中，产出类型为飞书播报摘要。
- [x] 模版变量包含活动、券波次/场次和统计时点。
- [x] 必含章节包含核心进度、偏差判断、异常来源、建议动作、风险与待确认项。
- [x] 必需能力为指标口径查询和预算归因分析。
- [x] 新模版不出现在新建策略对话首屏内置分析模版中。
- [x] 现有新建策略对话内置分析模版数量、顺序和快速填入行为保持不变。

## 创建、校验与预览

- [x] 三步创建流程按“分析内容 → 触发与范围 → 投递确认”组织。
- [x] 任务名称可自动起草并允许修改。
- [x] 活动和按需波次可从当前上下文带入并允许改选。
- [x] 模版变量可映射到有效上下文值。
- [x] 模版停用、必填上下文缺失、阈值无效、时间无效或接收目标为空时就地提示并阻止创建。
- [x] 投递位置支持站内通知、飞书用户和飞书群。
- [x] 支持一个或多个接收目标。
- [x] 通知预览展示任务名、触发原因、核心指标、AI 结论、建议动作和详情入口。
- [x] 预览不会创建任务或发送外部消息。
- [x] 支持“创建并启用”和“保存为暂停”。

## 实时监控降噪

- [x] 连续命中达到配置次数后才生成触发记录。
- [x] 冷静期内同严重程度重复命中不重复通知。
- [x] 冷静期内严重程度升级可生成一条升级提醒。
- [x] 依赖缺失、模版停用或上下文失效时任务进入“待处理”。
- [x] “待处理”状态展示原因和可执行处理动作。

## 运行记录与快照

- [x] 运行记录展示时间、任务、触发原因、分析结果、投递状态和产物入口。
- [x] 每次运行固定定时配置、活动上下文、模版、参数、能力和触发证据。
- [x] 编辑或复制任务不会改写已有运行记录。
- [x] 模版变化后，历史记录仍展示当次固定内容。
- [x] 运行失败和投递失败分别表达，不使用笼统“失败”。
- [x] 每次监控命中只生成分析、建议和通知，不修改线上策略配置。

- [x] 页面复用现有中性底色、蓝色主操作和表单 Token。
- [x] 触发类型使用紧凑标签，不使用大面积多色推荐卡片。
- [x] 状态色只承担运行中、暂停、待处理和失败语义。
- [x] 页面不展示“Mock/真实数据”等技术提示。
- [x] 1280px 下任务表格和右侧抽屉信息完整。

- [x] 390px 下字段、步骤、预览和底部操作不超出视口。

## 键盘与无障碍

- [x] Tab 可访问导航、指标、页签、筛选、任务行和主操作。
- [x] Enter/Space 可激活页签、场景、任务行、启停和选择控件。
- [x] Escape 可关闭创建、详情和预览抽屉。
- [x] 抽屉打开后焦点进入抽屉，关闭后返回原触发控件。
- [x] 不可见步骤和折叠内容不会接收焦点。
- [x] 字段错误通过 `aria-invalid` 和可访问描述关联。
- [x] 状态、触发类型和运行结果不只依赖颜色表达。
