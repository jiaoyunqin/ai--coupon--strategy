# 验收清单

## 审阅基线

- [x] 本轮覆盖促前、促中、历史对话、新建对话和共享侧栏。
- [x] 基础能力管理页仅继承共享视觉语言，没有被重新设计业务布局。
- [x] 页面业务数据、推荐算法、上下文隔离、会话状态和报告门禁未改变。
- [x] 不新增第三方字体、图标库、图片或网络依赖。

## 设计 token

- [x] `:root` 提供语义字号、间距、圆角、阴影、文本色、边框色、表面色和控件高度 token。
- [x] 主章节标题统一使用 20px token。
- [x] 子章节标题统一使用 15–16px token。
- [x] 卡片标题统一使用 13–14px token。
- [x] 正文和主要控件统一使用 12px token。
- [x] 辅助说明统一使用 11px token。
- [x] 微型标签统一使用 10px token。
- [x] 核心业务内容不再出现 6–9px 可见文字。
- [x] 核心组件间距优先使用 4 / 8 / 12 / 16 / 24 / 32px。
- [x] 核心圆角收敛为 6 / 8 / 12 / 16px 和胶囊值。
- [x] 核心阴影收敛为低、中、高三个层级。
- [x] 章节装饰色不替代成功、警告、危险或禁用状态色。

## 可读性

- [x] 促中 AI 建议、当前券批次、调整点、方案卡、监控和竞对说明默认缩放下可读。
- [x] 促前活动信息、候选方案、波次、券组、情报和历史洞察默认缩放下可读。
- [x] 历史对话消息、报告队列、报告正文和输入区默认缩放下可读。
- [x] 预算、时间、指标、风险和止损信息没有通过省略号或固定高度被截断。
- [x] 760px 下不通过缩小字体维持桌面布局。
- [x] 200% 缩放下核心内容仍可访问，无双向整页滚动。

## 控件尺寸

- [x] 标准按钮和 Tab 高度不低于 32px。
- [x] 高频主操作和选择器高度不低于 36px。
- [x] 表格内紧凑行操作可点击高度不低于 28px。
- [x] 图标按钮可点击区域不低于 32×32px。
- [x] 竞对动作不再出现约 13px 高的点击区域。
- [x] 方案标题选择入口不再出现约 18px 高的点击区域。
- [x] 增高控件后没有新增遮挡、错位或横向溢出。

## 标题与章节

- [x] 促前主章节继续按 01–04 排列，促中继续按 01–03 排列。
- [x] 促前“AI 券波次策略规划”下存在明确 H3 工作区标题。
- [x] 促前方案区不再出现 H2→H4 跳级。
- [x] 促中 `03.1` 不再重复展示“核心指标监控 / 当前核心指标监控”近同义标题。
- [x] H2、H3、H4 的视觉层级与语义层级一致。
- [x] 动态渲染后标题 ID 唯一且 `aria-labelledby` 目标有效。
- [x] 缺数波次、非默认活动和历史会话不出现标题跳级或编号错乱。

## 图标与符号

- [x] 核心操作图标使用统一 16px 描边 SVG。
- [x] 追问入口不再直接显示字符 `✦`。
- [x] 返回操作不再直接显示字符 `←`。
- [x] 添加操作不再直接显示字符 `＋`。
- [x] 关闭操作不再直接显示字符 `×`。
- [x] 全屏操作不再直接显示字符 `⛶`。
- [x] 展开操作不再直接显示字符 `↓`。
- [x] 图标均为 `aria-hidden`，按钮保留明确可访问名称。
- [x] 业务中的维度 `×`、状态变化 `→` 和日期范围 `—` 保留正确语义。

## 术语与标点

- [x] `AGENT 工作台` 已改为“策略工作台”。
- [x] `Knowledge` 已改为“知识库”。
- [x] `Datasource / DataSource` 已改为“数据源”。
- [x] `Skill` 已改为“技能”。
- [x] `Pre-campaign queue` 已改为“促前生成队列”。
- [x] `Report queue` 已改为“报告生成队列”。
- [x] AI、Agent、MCP、GMV、ROI、DAC、UV、Push 等必要缩写保持一致。
- [x] 元数据分隔统一使用 `·`。
- [x] 维度交叉统一使用 `×`。
- [x] 状态变化统一使用 `→`。
- [x] 日期范围统一使用 `—` 且两侧无空格。
- [x] 普通并列优先使用“、”或“与”，不滥用 `/`。
- [x] `3+X / 4+X` 等业务固定表达未被错误修改。

## 卡片与操作层级

- [x] 主章节、一级内容卡和内部信息组具有可辨识但不过度的层级。
- [x] 相同层级卡片使用一致的边框、圆角和阴影。
- [x] 一级内容卡不同时使用重边框、重阴影和多层渐变。
- [x] 内部信息组优先使用间距、分隔线或浅底色，不重复套用重卡片。
- [x] 每个操作区最多一个主操作。
- [x] 次要操作使用统一次级按钮。
- [x] 追问、展开和查看证据使用统一低强调样式。
- [x] 业务结论和指标的视觉权重高于辅助操作。
