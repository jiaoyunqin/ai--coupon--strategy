# 验收清单

## 模块位置与去重

- [ ] 01 内容区最上方展示 AI 策略调优建议。
- [ ] 建议模块位于当前券批次之前。
- [ ] 03 不再展示独立的 AI 策略调优建议。
- [ ] 03 不再展示旧采纳横幅。
- [ ] 页面只存在一套建议、预估效果和采纳操作。

## 建议内容

- [ ] 建议模块展示“待业务确认”或“已采纳预览”状态。
- [ ] 建议清单包含 3 条建议。
- [ ] 建议覆盖人群、券档、渠道与节奏。
- [ ] 每条建议展示标题、简述和影响标签。
- [ ] 建议只读取当前波次、端口和周期数据。
- [ ] 独立端或具体日期缺少拆解时不沿用主端全周期建议。
- [ ] 第二波、第三波不展示第一波建议。

## 采纳后预估效果

- [ ] 展示 ROI、增量 GMV 和无效成本变化三个预估指标。
- [ ] 预估明确为 AI 推演而非工作簿事实。
- [ ] 缺失预估显示“待灰度验证”或“暂无数据”。
- [ ] 预估值不跨波次、端口或周期拼接。

## 采纳预览与取消

- [ ] 点击一键采纳并确认后状态变为“已采纳预览”。
- [ ] 采纳后主按钮变为“取消采纳预览”。
- [ ] 取消后移除全部预览标签和高亮。
- [ ] 采纳和取消均不修改 `mid38SourceSnapshot`。
- [ ] 采纳和取消均不触发真实发券、预算、人群或渠道接口。
- [ ] 切换波次、端口或周期后自动清除采纳预览。

## 当前券批次联动

- [ ] 300-40 显示“规模承接”预览标签。
- [ ] 1500-150、2000-200、3000-300 显示“限制泛发 / 定向验证”预览标签。
- [ ] 券批次原始指标和值保持不变。
- [ ] 储备、实验和对照分组交互保持可用。

## 人群联动
