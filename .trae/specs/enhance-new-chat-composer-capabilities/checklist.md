# 验收清单

## 输入工具栏

- [x] 新建策略对话工具栏按“添加、技能、上下文标签、模型、清空、发送”组织。
- [x] 输入区继续复用唯一的 `newChatComposer` 节点，没有创建第二套输入控件。
- [x] 首次进入时默认选中“预算归因分析”和两个系统预置技能。
- [x] 首次进入时模型默认为 `GPT-5.6-Luna Max`。
- [x] 响应期间添加、技能、模型、清空和发送均不可修改状态。
- [x] 响应完成后所有原本可用的控件恢复。

## 技能菜单

- [x] “技能”按钮可打开和关闭技能菜单。
- [x] 技能菜单展示 6 个 Skill Catalog 技能，名称均为中文业务名称。
- [x] 菜单顶部提供技能搜索。
- [x] 搜索支持按名称、说明和标签过滤。
- [x] 搜索无结果时展示明确空状态。
- [x] “预算归因分析”默认选中且可取消。
- [x] “预算枚举查询”和“指标口径查询”标记为系统预置、保持选中且不可取消。
- [x] 舆情趋势洞察、大促播报和预算异常检测可独立选择和取消。
- [x] 已选可选技能在工具栏显示紧凑标签。
- [x] 技能标签可独立移除，并与菜单选中状态同步。
- [x] 聚焦技能时可查看类型、标签和说明。
- [x] 桌面端技能详情使用列表与详情分层展示。
- [x] 窄屏技能详情在当前条目内联展示。
- [x] “添加新技能”打开现有技能管理视图，没有创建重复页面。
- [x] 技能操作不发送消息、不修改输入内容。

## 添加菜单

- [x] “添加”按钮提供粘贴链接、接入资源和上传本地文件三个入口。
- [x] 链接输入只接受 `http://` 或 `https://`。
- [x] 无效或空链接展示就地错误且不创建标签。
- [x] 有效链接创建可读、可移除的链接标签。
- [x] 页面不会因为添加链接而发起抓取或解析请求。
- [x] 资源选择只展示已启用的知识库和数据源资源。
- [x] 资源支持按名称筛选。
- [x] 已选择资源显示资源类型和名称。
- [x] 相同资源不可重复添加。
- [x] 选择本地文件后只记录文件名、大小和类型。
- [x] 页面不读取文件正文、不上传本地文件。
- [x] 取消系统文件选择器不改变当前状态。
- [x] 链接、资源和文件标签均可独立移除。
- [x] 移除一个上下文不影响其他上下文、技能、模型或输入内容。
- [x] 重置新建对话后链接、资源和文件标签清空。

## 模型选择

- [x] 模型选择器包含 3 个 Luna 模型和 6 个外部模型。
- [x] 模型按“券策略模型”和“外部模型”分组。
- [x] 9 个模型名称和 Value 与 Model Catalog 一致。
- [x] 模型列表不展示使用率、费用、配额或“NEW”标签。
- [x] 切换模型后工具栏立即显示新名称。
- [x] 切换模型后 `newChatState.selectedModel` 使用稳定 Value。
- [x] 切换模型展示现有 Toast 提示。
- [x] 模板筛选、技能选择、添加上下文和新建对话重置不会意外改变当前模型。

## 提问示例

- [x] 空对话输入框下方展示 3 条 Question Examples。
- [x] 提问示例位于输入框与内置策略模板之间。
- [x] 3 条示例顺序和完整文案与 spec 一致。
- [x] 示例文本在桌面和窄屏下完整可读。
- [x] 点击示例只替换输入框内容并聚焦输入框。
- [x] 键盘 Enter/Space 激活示例与点击行为一致。
- [x] 示例不会自动发送或新增消息。
- [x] 示例不会修改技能、上下文和模型选择。
- [x] 首条消息发送后空状态示例隐藏。
- [x] 消息态现有动态推荐问题保持正常。

## 菜单与状态

- [x] 技能菜单和添加菜单同时最多打开一个。
- [x] 打开另一个菜单时原菜单自动关闭。
- [x] 点击菜单外部可关闭当前菜单。
- [x] Escape 可关闭当前菜单。
- [x] 菜单关闭后焦点返回对应触发按钮或下一步输入控件。
- [x] `resetNewChat()` 关闭所有菜单并恢复默认技能集合。
- [x] 技能、上下文和模型不会拼接进可见用户消息正文。
- [x] 页面不宣称已完成真实技能调用、资源读取、文件上传或外部模型调用。

- [x] 添加、技能、标签移除、清空和发送图标按钮具有中文可访问名称。
