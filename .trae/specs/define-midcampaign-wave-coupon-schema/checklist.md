# 验收清单

## 统一业务模型

- [x] 当前波次与下一波次使用同一套波次券方案字段口径。
- [x] 一个波次可包含多个券方案单元。
- [x] 一个券方案单元可包含多个渠道规则。
- [x] 实验组与券类型分离，并关联基准组和单一变量。
- [x] 渠道动作只使用发券、催用、引流、仅入口和不启用。
- [x] 渠道能力限制使用独立字段，不埋在通用备注中。

## 波次 P0 完整性

- [x] 每个波次包含活动、波次、端、正式期、每日时段、特殊时段、发放节奏和状态。
- [x] 每个券方案单元包含名称、业务角色、券机制、券档、人群、触发条件、领取规则、有效期、发放形式、算法策略、时段和状态。
- [x] 每条渠道规则包含券方案单元、渠道、渠道角色、动作、人群、时段、催用、计划复用和能力限制。
- [x] 每个实验包含主题、基准组、实验组、单一变量、涉及券单元、人群、渠道和时间窗。
- [x] 每个波次包含频控、渠道互斥、跨端关系、重复触达和异常处理约束。

## 促中调优 P1 完整性

- [x] 方案包含主目标、优先级和适用条件。
- [x] 预算、预估效果、证据、联合护栏和回滚均有独立字段。
- [x] 源表没有的预算或效果值明确标记为 Mock/推演。
- [x] 缺失值显示“暂无数据”或“待灰度验证”，不补零、不跨上下文回填。

## 01 当前波次调优

- [x] 首屏只展示波次摘要和需要决策的差异项。
- [x] 差异表包含调整维度、对象、当前配置、事实/问题、建议调整、影响范围、预期效果、护栏/回滚和决策状态。
- [x] 调整对象可定位到券方案单元、渠道规则、实验或护栏。
- [x] 受影响的券单元、渠道、实验和完整只读快照可按需下钻。
- [x] 未变化配置不在首屏重复铺陈。

## 02 下一波次方案明细与调优

- [x] 选中候选按波次总览、券方案单元、渠道矩阵、实验护栏和可调项顺序展示。
- [x] 券方案单元表包含业务角色、券机制/券档、人群与触发、领取规则、时段、策略/实验、发放形式和状态。
- [x] 渠道矩阵能快速识别各券单元的渠道动作。
- [x] 渠道单元格可下钻人群、时段、发放方式、催用、计划复用和能力限制。
- [x] 可调项包含当前值、推荐值、合法范围、联动影响、风险护栏和当前选择。
- [x] 切换候选后所有方案明细和调优上下文同步更新。

## 来源与安全边界

- [x] 工作簿事实、Mock 推演和用户调整结果可被明确区分。
- [x] 页面不展示或序列化配置 ID、活动 ID、投放计划 ID、点位数字 ID、BSK 或内部链接。
- [x] 对象关联使用稳定业务别名。
- [x] 页面、弹层、会话和审计快照不出现 `undefined`。
- [x] Mock 与调优操作不触发真实发券、预算、人群或渠道配置。
