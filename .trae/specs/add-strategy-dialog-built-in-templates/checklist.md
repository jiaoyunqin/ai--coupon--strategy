# 验收清单

## 范围与内容

- [x] “新建策略对话”保留现有欢迎信息和三条推荐问题。
- [x] 推荐问题下方新增系统内置模板区。
- [x] 模板区不包含“精选模板”“我收藏的”“我创建的”、搜索或创建入口。
- [x] 默认“全部”筛选展示 9 个模板，顺序为促前 4 个、促中 5 个。
- [x] 9 个模板的标题、场景说明和完整问题与 `spec.md` 的 Template Catalog 一致。
- [x] 页面不展示使用次数、收藏数、Mock/真实数据、Revision 等无关技术或运营信息。

## 标签筛选

- [x] 模板区提供“全部 / 促前 / 促中”三个互斥筛选项。
- [x] “促前”只展示 4 个促前模板。
- [x] “促中”只展示 5 个促中模板。
- [x] 切回“全部”恢复展示全部 9 个模板。
- [x] 筛选项具备清晰的视觉选中态和可访问状态语义。
- [x] 筛选不会修改输入框内容、推荐问题或工作台活动状态。

## 活动与波次上下文

- [x] 促前模板读取当前促前规划活动，而不是固定写死活动。
- [x] 促中模板读取当前促中活动、年份和当前分析波次，而不是复用促前上下文。
- [x] 填入内容以“活动信息”开头，并包含活动名称及可用活动周期。
- [x] 存在适用券波次/场次时，填入独立的“券波次/场次”行。
- [x] 不存在有效券波次/场次时，整行省略。
- [x] 不使用“暂无数据”“待选择”、空括号或虚构信息替代缺失波次。
- [x] 输入框中的“问题”内容与所选模板完整问题一致。

## 仅填入行为

- [x] 点击模板卡片或“使用模板”产生相同的填入结果。
- [x] 模板内容整体替换输入框原内容，不与旧模板拼接。
- [x] 填入后输入框自动调整高度并获得焦点。
- [x] 填入内容可继续手动编辑。
- [x] 模板点击不调用发送逻辑。
- [x] 模板点击不新增用户消息或 Agent 消息。
- [x] 模板点击不启动思考进度、生成回复或展开报告。
- [x] 模板点击后仍停留在新建策略对话空状态，模板区继续可见。

## 视觉与响应式

- [x] 模板卡片只展示阶段标签、标题、简短场景说明和使用操作。
- [x] 模板区沿用当前新建对话的字体、蓝色强调、圆角、边框和阴影规则。
- [x] 卡片悬停、聚焦和按下状态可感知且不引发布局跳动。
- [x] 桌面宽屏下模板信息层级清晰，卡片密度不造成文本堆砌。
- [x] 1280px、1024px、860px 和 760px 视口下模板区无页面级横向溢出。
- [x] 长标题和场景说明不被不可恢复地截断。
- [x] 模板内容区可独立纵向滚动，底部输入区保持现有布局。

## 键盘与无障碍

- [x] Tab 可聚焦全部筛选项和所有可见模板操作。
- [x] Enter/Space 可切换筛选并使用模板。
- [x] 筛选后焦点不会落在已隐藏模板上。
- [x] 每个模板操作的可访问名称包含模板标题。
- [x] 焦点轮廓在浅色背景上清晰可见。
- [x] 模板列表更新不会产生重复 ID、失效 ARIA 引用或严重无障碍问题。

## 回归与工程检查

- [x] 现有三条推荐问题仍只填入输入框且内容正确。
- [x] 手动输入和发送行为保持现状。
- [x] 清空输入、模型选择和附件占位行为保持现状。
- [x] 返回策略工作台行为保持现状。
- [x] 从促前/促中方案及数据入口进入的新建对话上下文行为不受影响。
- [x] “促前券档位设计”和“促中预算紧张”历史会话不受影响。
- [x] JavaScript 语法检查通过。
- [x] 静态重复 ID 检查通过。
- [x] `git diff --check` 通过。
- [x] 浏览器控制台无本次变更新增错误。
