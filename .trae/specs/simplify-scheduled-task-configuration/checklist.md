# 验收清单

## 管理首页

- [ ] 首屏展示“运行中”“今日已执行”“今日已推送”“异常”四项紧凑统计。
- [ ] 四项统计与任务列表、运行记录使用同一数据源。
- [ ] 首页仅保留名称搜索和一个状态下拉筛选。
- [ ] 首页不再展示实时监控/每日推送类型筛选和运行记录页签。
- [ ] 列表展示任务名称、任务模版、活动范围、执行计划、当前状态、最近推送和下次执行。
- [ ] 任务可在列表中直接启用或暂停。
- [ ] 任务操作包含编辑、立即执行和删除。
- [ ] 空结果状态清晰，并可恢复搜索或状态筛选。

## 单页配置面板

- [ ] 新建和编辑使用同一个单页面板，不再使用三步导航。
- [ ] 面板仅包含任务名称、任务模版、活动范围、开始时间、执行频率、时区和通知对象。
- [ ] 底部仅提供“取消”和“确定”。
- [ ] 任务名称默认由任务模版名称和活动名称生成，并允许修改。
- [ ] 任务模版仅可选择已启用且具备可运行默认值的模版。
- [ ] 活动为必选项，并可在同一控件内按需缩小到波次或场次。
- [ ] 未选择波次或场次时默认覆盖整个活动。
- [ ] 执行频率提供每 30 分钟、每小时、每天、每周和每月。
- [ ] 每周和每月的执行日由开始时间确定。
- [ ] 时区默认使用当前项目时区。
- [ ] 通知对象默认当前用户，并可改选一个飞书群。
- [ ] 不支持同时选择多个通知对象。
- [ ] 必填项缺失时就地提示并阻止提交。
- [ ] 新建任务成功后默认启用。
- [ ] 编辑保存后保留原启用或暂停状态。
- [ ] 编辑任务不改写历史运行记录。
- [ ] 从任务模版创建定时任务时自动带入来源模版。

## 删除实时监控

- [ ] 新建和编辑面板不再提供“实时监控”触发类型。
- [ ] 首页、筛选、列表和详情不再展示“实时监控”标签。
- [ ] 页面不再出现指标关系、阈值、连续命中、冷静期或严重程度配置。
- [ ] 页面不再出现实时监控场景快速起草卡片。
- [ ] 固定周期执行的既有任务统一表述为定时巡检。
- [ ] 既有周期任务保留名称、模版、活动范围、执行计划、状态和运行记录。
- [ ] “立即检查”和“立即生成”统一为“立即执行”。
- [ ] “立即执行”不改变下一次计划执行时间。

## 任务模版边界

- [ ] 配置面板仅展示已选模版名称和“查看模版”入口。
- [ ] 配置面板不展示模版参数表、参数映射、能力状态或产出章节。
- [ ] 任务详情不展示指标、阈值、完整任务指令或能力依赖。
- [ ] 任务详情提供关联任务模版入口。
- [ ] 指标、阈值、业务判断、分析指令、参数、能力和产出定义均在任务模版中查看。
- [ ] 缺少可运行默认值的模版提供前往模版编辑的处理入口。
- [ ] 界面不展示完整 Prompt、内部能力 ID、技术版本或“Mock/真实数据”提示。

## 任务详情与状态

- [ ] 任务详情展示活动范围、执行计划、通知对象、当前状态和运行记录。
- [ ] 运行记录展示执行时间、执行结果、推送结果和产物入口。
- [ ] 任务状态与单次执行结果使用不同字段和文案。
- [ ] 运行中表示当前已启用的任务数量。
- [ ] 今日已执行按当日运行实例统计。
- [ ] 今日已推送仅统计投递成功的运行实例。
- [ ] 异常覆盖执行失败和推送失败，并能在详情中区分。
- [ ] 暂停任务不产生新的计划运行记录。

## 响应式与无障碍

- [ ] 1280px 和 1024px 下列表与配置面板信息完整且无横向溢出。
- [ ] 760px 和 390px 下列表转为紧凑卡片，配置字段单列排列。
- [ ] 窄视口下底部操作保持可见且不遮挡字段。
- [ ] Tab 可访问搜索、筛选、任务操作和全部表单字段。
- [ ] Enter/Space 可完成选择、启停、立即执行和提交。
- [ ] Escape 可关闭配置面板和任务详情。
- [ ] 面板打开后焦点进入面板，关闭后返回原触发控件。
- [ ] 字段错误通过可访问描述关联。
- [ ] 状态和错误不只依赖颜色表达。

## 回归与工程检查

- [ ] 任务模版创建、编辑、详情和发起一次任务保持正常。
- [ ] 任务模版详情和保存结果中的“创建定时任务”入口保持正常。
- [ ] 新建策略对话及现有促前、促中 Demo 链路无新增回归。
- [ ] JavaScript 语法检查通过。
- [ ] 静态和运行时重复 ID 检查通过。
- [ ] `git diff --check` 通过。
- [ ] 浏览器控制台无本次变更新增错误。
- [ ] 基础无障碍检查无新增严重问题。
