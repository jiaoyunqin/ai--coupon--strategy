# 验收清单

## 范围与章节

- [x] 新增效率洞察位于 `03.2 核销与实验分析`，不新增或改变 `03.1—03.4` 编号。
- [x] 03 仍按核心指标、核销与实验、竞对、归因的顺序展示。
- [x] 现有趋势、消费券实验和一般归因结论保持可用。
- [x] 本次未增加异常检测、异常阈值、异常原因贡献度或自动异常归因模块。
- [x] 页面不展示“Mock/真实数据”“Revision”等技术提示。

## 洞察首屏

- [x] 首屏包含类目、人群和点位三张效率洞察卡。
- [x] 每张卡仅展示一个核心结论、2—3 个关键指标和一条建议。
- [x] 每张卡提供明确的“查看详情 / 收起详情”操作。
- [x] 同一时间最多展开一个详情面板。
- [x] 切换详情时不重复铺设相同宽表。
- [x] 三张卡及详情统一使用 03 章节主题色。

## 数据契约

- [x] 类目、人群和点位 Mock 数据按 `contextKey` 隔离。
- [x] 百分比、金额、人数和比率以可计算数值存储，并由统一格式化函数展示。
- [x] `GMV 占比 - 预算占比` 的效率差计算正确。
- [x] `核销 UV 占比 - 领券 UV 占比` 的份额差计算正确。
- [x] 缺失值保持为空或“暂无数据”，不使用 0 替代。
- [x] 不使用其他活动、年份、波次、周期或端口数据补齐当前缺口。
- [x] 结论、关键指标和建议均可追溯到同一上下文的明细数据。

## 类目转化效率

- [x] 类目卡展示 GMV、预算或效率差相关的核心证据。
- [x] 类目建议明确区分优先验证、保量或收缩方向。
- [x] 详情支持“行业效率 / 行业 × 档位”切换。
- [x] 行业效率图正确对比 GMV 占比和预算占比。
- [x] 行业表包含支付 GMV、GMV 占比、核销预算、预算占比、效率差和券 GMV 渗透。
- [x] 行业表包含可用的支付用户、订单、ARPU、订单频次和客单字段。
- [x] 行业 × 档位表包含行业、券档、预算占比、券引导 GMV 占比和效率差。
- [x] 增量兑换比仅在数据存在时展示。

## 人群 × 客单价效率

- [x] 人群卡联合核销率、平均客单和规模形成结论。
- [x] 人群建议不以客单价单指标直接判断扩量。
- [x] 详情支持“消费力等级 / 八大人群”切换。
- [x] 图表以核销率为一轴、平均客单价为另一轴。
- [x] 气泡大小正确表达订单 GMV 或核销规模，并有图例说明。
- [x] 消费力等级表覆盖 L1—L5 的领券、核销、预算、订单 GMV 和客单。
- [x] 八大人群表覆盖八类人群的领券、核销、核销率、预算、订单 GMV 和客单。
- [x] 可计算时展示核销份额与领券份额差、GMV 份额与预算份额差。
- [x] 不生成参考表中不存在的客单价分桶数据。

## 点位效率

- [x] 点位数据下钻到具体资源位，不只停留在聚合渠道。
- [x] 点位卡同时考虑核销率、成本、GMV 和预算形成结论。
- [x] 点位图正确表达领券成本与核销率的关系。
- [x] 点位表包含领券 UV、领券占比、核销 UV、核销率、核销预算和预算占比。
- [x] 点位表包含引导 GMV、GMV 占比、领券成本、订单数和客单价。
- [x] 点位状态至少区分高效承接、规模底座、低效收缩和暂无数据。
- [x] 内容异形卡等无数据点位不显示虚构数值。
