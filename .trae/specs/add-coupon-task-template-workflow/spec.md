# 消费券任务模版创建与运行 Demo Spec

## Why

当前“内置分析模版”只能把固定问题填入新建策略对话，尚不能定义一次任务需要填写什么、调用哪些能力、交付什么产物，也不能从模版直接创建独立任务。参考 Aime 与 iDA，需要补齐“任务模版”这一独立产品对象，让高频券策略场景能够以统一输入、统一产出和可追溯任务反复运行。

## What Changes

- 新增工作区级“任务模版”入口和模版库，支持查看内置模版、我创建的模版、搜索与阶段筛选。
- 保留现有“内置分析模版”快速填入对话的行为，并在模版详情中增加“发起任务”入口。
- 支持“从零创建”和“从已完成对话沉淀”两种创建方式。
- 新增两步创建流程：
  - 第一步定义任务指令、变量、任务产出和执行能力。
  - 第二步确认名称、简介、适用阶段、场景标签和可见范围。
- 支持通过 `{变量}` 和手动选择文本生成变量，并配置类型、默认值、说明和必填状态。
- 为任务模版增加明确的产出契约，包括决策结论、调优动作、效果预估、证据依据、风险与待确认项。
- 模版只声明所需能力，运行时再映射到已启用技能；技能缺失、停用或权限不足时，在发起前明确阻断或降级。
- 使用任务模版时展示结构化参数表单，自动带入当前活动、阶段和波次；校验通过后创建一次独立任务实例。
- 以“末波次预算紧张调优”为主 Demo，完整演示创建模版、填写参数、发起任务和生成结构化调优方案。
- Demo 使用本地静态数据与页面内状态，不新增后端模版服务、真实任务调度或线上营销配置写入。

## Research Decisions

### Aime 与 iDA 能力取舍

| 能力 | Aime | iDA | 本 Demo 决策 |
| --- | --- | --- | --- |
| 模版入口 | 独立模版广场，支持公开、收藏、我创建的、搜索、导入 | 新对话首页内展示全部、精选、收藏、我创建的与搜索 | 增加独立“任务模版”入口；新对话保留紧凑推荐区 |
| 创建路径 | 从已完成任务沉淀、从零创建 | 从零创建 | 两条路径都保留，优先完整实现从零创建 |
| 指令编辑 | 完整需求指令，支持参数智能提取 | 指令模板支持 `{变量}`、划词变量和 `@` 技能 | 支持 `{变量}` 与手动转变量；Demo 的“智能提取”只对内置示例做确定性提取 |
| 参数配置 | 说明、默认值、必填、上传文件 | 参数变量、类型、默认值、说明、必填 | 采用两者交集，并增加活动/波次上下文变量 |
| 能力配置 | 扩展中配置 Agent、Skill、MCP | 指令中通过 `@` 引用技能 | 用户选择业务能力标签，系统映射技能；不要求用户理解技术技能 ID |
| 基本信息 | AI 起草名称、简介、职能、类型、可见范围 | 名称、简介、场景、公开范围、封面 | 保留名称、简介、阶段、场景、可见范围；不做封面上传 |
| 任务运行 | 单次、批量、链接发起，运行后形成独立任务 | 使用模版进入新对话 | 首期只做单次任务；每次运行创建独立任务实例并保留来源 |
| 产出定义 | 主要由指令描述 | 主要由指令描述 | 增加券策略专用“任务产出”配置，作为本产品差异能力 |

### 产品对象边界

- **提问模版**：服务于当前对话，负责快速填入一个可编辑问题，不独立创建任务。
- **任务模版**：定义一次可重复运行的任务入口，包含任务指令、变量、产出契约和能力依赖。
- **技能**：提供预算归因、指标口径、异常检测等专业执行能力，不独立生成任务。
- **任务实例**：任务模版每运行一次产生一个新实例，固定当次参数、上下文、模版和能力快照。
- **策略产物**：任务运行结果，固化结论、证据、调优参数、效果预估和风险，不反向修改模版。

一个任务模版 MAY 组合多个能力，一个能力 MAY 被多个模版复用。没有任务模版时，用户仍可在对话中自然语言提问并触发技能。

## Product Capability Design

### 1. 任务模版入口与模版库

- 在“策略工作台”中新增“任务模版”入口，位置与“新建策略对话”同级。
- 模版库提供：
  - 来源页签：`全部 / 内置 / 我创建的`
  - 阶段筛选：`全部阶段 / 促前 / 促中 / 复盘`
  - 名称或场景搜索
  - `新建任务模版`主操作
- 卡片仅展示阶段、名称、场景说明和产出类型，不展示使用次数、收藏数、Revision、Mock/真实数据等运营或技术信息。
- 现有新建对话内“内置分析模版”保持紧凑推荐形态，并增加“查看全部”和“新建任务模版”入口。

### 2. 两种创建路径

#### 从零创建

用户在模版库点击“新建任务模版”，进入两步创建弹窗。

#### 从对话沉淀

已完成并形成结构化策略产物的对话提供“沉淀为任务模版”。系统预填：

- 对话中的任务目标与指令。
- 已确认的活动、阶段、波次等候选变量。
- 本次实际使用的能力标签。
- 产物中已经出现的标准章节。

用户仍须检查变量和产出契约后保存，不允许无确认自动发布。

### 3. 第一步：任务指令、变量、产出和能力

#### 任务指令

- 使用自然语言定义任务目标和分析要求。
- `{变量名}` 自动生成同名变量。
- 用户选择指令中的文本后可执行“设为变量”。
- 删除变量时，指令中的对应占位符恢复为普通文本。
- 指令为空或存在未配置的占位符时不能进入下一步。

#### 变量配置

首期支持以下类型：

| 类型 | 适用示例 |
| --- | --- |
| 单行文本 | 候选策略名称、补充约束 |
| 数值 | 预算金额、可覆盖人数、目标达成率、ROI 底线 |
| 单选 | 风险偏好、是否保量、分析口径 |
| 日期或日期范围 | 活动周期、分析窗口 |
| 链接 | 策略文档、实验报告 |
| 文件 | 临时上传的策略材料 |
| 活动上下文 | 当前促前或促中活动 |
| 波次上下文 | 当前活动下的券波次或场次 |

每个变量 SHALL 支持配置：

- 展示名称。
- 变量键。
- 类型。
- 填写说明。
- 默认值。
- 是否必填。
- 是否从当前活动上下文自动带入。

#### 任务产出

创建者 SHALL 明确选择产出类型和必含章节。

产出类型：

- 调优方案。
- 分析报告。
- 复盘结论。
- 飞书播报摘要。

券策略标准章节：

- 决策摘要。
- 当前问题与触发信号。
- 调优动作。
- 方案对比。
- 效果预估。
- 数据与实验依据。
- 风险、缺失数据与止损条件。
- 待确认参数快照。

“效果预估”必须区分可计算值、方向性判断和缺失数据，不得用固定模板伪造精确 GMV、ROI 或预算结果。

#### 执行能力

- 系统根据任务指令和产出章节推荐能力标签。
- 创建者可增删推荐能力。
- 模版保存能力标签，不强绑定具体技能 ID。
- 运行前将能力标签解析为当前已启用技能。
- 任务模版详情中展示业务名称，例如“预算归因分析”“指标口径查询”，不展示内部技术名称。

### 4. 第二步：基本信息

系统根据第一步内容起草，用户确认：

- 模版名称。
- 一句话简介。
- 适用阶段：促前、促中或复盘。
- 调优场景标签。
- 可见范围：仅自己、当前工作区。
- 状态：保存为草稿、保存并启用。

首期不提供全局公开、跨空间导入、收藏、批量运行和模版链接发起。

### 5. 模版详情与管理

模版详情按以下层级展示：

1. 场景与简介。
2. 需要填写的参数。
3. 预期产出。
4. 所需能力与当前可用状态。
5. 任务指令，默认折叠。

我创建的模版支持：

- 编辑。
- 复制。
- 启用或停用。
- 发起任务。

内置模版只支持查看与发起任务。编辑已启用模版时 SHALL 形成新的页面内版本，历史任务继续引用原运行快照；界面无需暴露技术性 Revision 文案。

### 6. 使用模版发起任务

- 用户点击“发起任务”后进入参数表单。
- 活动、阶段和波次优先从当前工作台上下文带入。
- 自动带入值必须可见、可修改，并标明来源为“当前上下文”。
- 必填项缺失、变量格式错误或能力不可用时，提交按钮不可用并给出就地原因。
- 提交前展示本次运行摘要：
  - 模版名称。
  - 活动与波次。
  - 关键参数。
  - 将使用的能力。
  - 预期产出。
- 提交后创建独立任务实例，不把参数拼接成用户可见的长 Prompt。
- 任务完成后展示来源模版、运行参数和数据边界，可继续追问。

## Canonical Demo: 末波次预算紧张调优

### 模版定义

**名称**：末波次预算紧张调优

**简介**：比较 V1/V15 人群策略，在预算容量内形成可解释的覆盖方案。

**任务指令**：

```text
针对{活动}的{券波次/场次}，在{预算可覆盖人数}万用户的容量下，
比较{候选策略}在大盘 L4/L5 与 jp/t8 重点人群上的增量 GMV 兑换比、
人群规模和支付表现。结合{是否要求重点人群保量}与{风险偏好}，
给出推荐方案、保量备选、覆盖测算、效果边界、上线风险和待确认参数。
```

**变量**：

| 变量 | 类型 | 必填 | 默认或来源 |
| --- | --- | --- | --- |
| 活动 | 活动上下文 | 是 | 当前促中活动 |
| 券波次/场次 | 波次上下文 | 是 | 当前分析波次 |
| 预算可覆盖人数 | 数值 | 是 | `7200` 万 |
| 候选策略 | 单选 | 是 | `V1 与 V15` |
| 是否要求重点人群保量 | 单选 | 是 | `否` |
| 风险偏好 | 单选 | 是 | `平衡` |

**能力标签**：

- 指标口径查询。
- 预算归因分析。
- 预算异常检测。
- 实验效果分析。

**产出章节**：

- 决策摘要。
- V1/V15 总体对比。
- L4、L5 与 jp/t8 同位比较。
- 人群规模与预算覆盖测算。
- 推荐方案与保量备选。
- 效果预估边界。
- 风险、缺失数据与止损条件。
- 待确认配置快照。

### Demo 运行证据

Demo SHALL 复用现有案例数据：

- V1/V15 增量 GMV 兑换比为 `6.32 / 6.24`，差异为 `0.08`。
- L4、L5、jp/t8 同位兑换比分别约为 `6.02 / 6.08 / 6.01`。
- jp/t8 人群池约 `6,400 万`，大盘 L4-L5 人群池约 `8,000 万`。
- V15 总体增量偏低主要受人群规模约束，不能解释为兑换效率显著更差。

### Demo 标准产出

1. **决策摘要**
   - 推荐：不在 V1/V15 硬标签中二选一，在大盘 L1-L5 中按预期增量排序，由算法在预算容量内选择部分人群。
   - 保量备选：如业务必须保证重点人群触达，先设置 jp/t8 保底层，再将剩余预算交给算法。
2. **覆盖测算**
   - 预算容量 `7,200 万` 可覆盖大盘 L4-L5 的 `90%`。
   - 同等容量高于 jp/t8 人群池规模，但超出部分是否可继续用于算法覆盖，取决于单人成本、库存和业务规则。
3. **核心依据**
   - 总体和同位兑换比均接近，现有数据不足以证明任一硬标签策略显著更优。
   - jp/t8 人群规模只有大盘 L4-L5 的约 `80%`，量级差异会限制总增量。
4. **效果预估**
   - 可计算：覆盖率、人群容量差、预算可覆盖规模。
   - 方向判断：算法排序预计比单一硬标签更能利用有限预算。
   - 不可计算：精确增量 GMV、ROI 和补贴额；缺少单人成本、显著性和样本稳定性时不得生成精确值。
5. **风险与待确认**
   - 算法可能挤占关键 L4-L5 用户。
   - 需补充 X 券单人成本、剩余库存、实验显著性和业务保量底线。
   - 上线后监控预算流速、券流速、领取 UV、核销 UV、核销率、客单和增量兑换比。
6. **待确认配置快照**
   - 活动、波次、预算容量。
   - jp/t8 保底比例。
   - 算法覆盖范围。
   - 观察窗口和止损阈值。
   - 仅生成配置草案，不直接发券或修改预算。

## ADDED Requirements

### Requirement: 独立任务模版入口

系统 SHALL 提供独立于技能管理和新建策略对话的“任务模版”入口，并允许用户浏览内置与自建任务模版。

#### Scenario: 浏览任务模版库

- **WHEN** 用户进入“任务模版”
- **THEN** 默认展示全部可用模版
- **AND** 用户可按来源、业务阶段和关键词筛选
- **AND** 每张卡片展示阶段、名称、场景和产出类型
- **AND** 页面提供“新建任务模版”入口

### Requirement: 从零创建任务模版

系统 SHALL 通过两步流程创建任务模版，并在保存前校验任务指令、变量、产出和基本信息。

#### Scenario: 使用变量创建模版

- **WHEN** 用户输入包含 `{活动}`、`{券波次/场次}` 和 `{预算可覆盖人数}` 的任务指令
- **THEN** 系统生成三个变量配置项
- **AND** 用户可配置类型、说明、默认值和必填状态
- **AND** 未完成必填配置前不能进入第二步

#### Scenario: 完成基本信息并保存

- **WHEN** 用户完成第一步并进入第二步
- **THEN** 系统起草名称、简介、阶段和场景标签
- **AND** 用户可修改起草内容和可见范围
- **AND** 保存后模版出现在“我创建的”

### Requirement: 从已完成对话沉淀模版

系统 SHALL 允许将已形成结构化策略产物的对话沉淀为任务模版草稿。

#### Scenario: 从促中调优对话创建

- **WHEN** 用户在已完成的促中策略对话中选择“沉淀为任务模版”
- **THEN** 系统预填任务目标、候选变量、能力标签和产出章节
- **AND** 用户必须检查并确认后才能保存
- **AND** 原对话和策略产物保持不变

### Requirement: 明确任务产出

系统 SHALL 要求任务模版定义产出类型和必含章节，并在运行前向使用者展示。

#### Scenario: 配置调优方案产出

- **WHEN** 创建者选择“调优方案”
- **THEN** 系统默认勾选决策摘要、调优动作、效果预估、证据依据、风险与待确认项
- **AND** 创建者可调整章节
- **AND** 任务详情展示最终产出结构

### Requirement: 模版与技能解耦编排

系统 SHALL 使用能力标签描述任务需求，并在运行时解析可用技能。

#### Scenario: 所需技能可用

- **WHEN** 用户准备运行“末波次预算紧张调优”
- **THEN** 系统展示指标口径、预算归因、异常检测和实验分析能力均可用
- **AND** 用户可以查看并调整非系统必需能力
- **AND** 任务实例固定本次能力快照

#### Scenario: 所需技能不可用

- **WHEN** 必需能力对应技能停用、缺失或无权限
- **THEN** 系统在提交前指出具体能力和处理方式
- **AND** 若该能力影响核心结论则阻止运行
- **AND** 若只影响可选章节则允许移除章节后继续

### Requirement: 通过参数表单发起任务

系统 SHALL 在运行任务模版时展示结构化参数表单，并在校验成功后创建独立任务实例。

#### Scenario: 自动带入活动上下文

- **WHEN** 用户从当前促中波次打开模版
- **THEN** 活动和波次自动填入
- **AND** 自动值标记为来自当前上下文
- **AND** 用户可以选择其他有效活动或波次

#### Scenario: 参数不完整

- **WHEN** 必填参数为空或数值格式无效
- **THEN** 页面就地标记问题
- **AND** 不创建任务实例
- **AND** 不生成虚构默认值

#### Scenario: 参数完整

- **WHEN** 所有必填参数和能力检查通过且用户点击“发起任务”
- **THEN** 系统创建新的任务实例
- **AND** 固定模版、参数、上下文和能力快照
- **AND** 进入任务执行与结果视图

### Requirement: 末波次预算紧张调优 Demo

系统 SHALL 使用 Canonical Demo 的数据和产出结构演示一次完整任务运行。

#### Scenario: 运行默认示例

- **WHEN** 用户以 `7200 万`预算覆盖容量、`不要求重点人群保量`和`平衡`风险偏好发起任务
- **THEN** 结果展示 V1/V15 总体对比和 L4/L5/jp/t8 同位对比
- **AND** 指出 V15 增量偏低主要来自人群规模而非兑换效率
- **AND** 推荐大盘 L1-L5 算法覆盖
- **AND** 提供 jp/t8 保底加剩余预算算法分配的备选
- **AND** 明确精确 GMV、ROI 和补贴额不可计算的原因
- **AND** 输出待确认配置快照但不执行线上变更

### Requirement: 模版来源与结果追溯

系统 SHALL 在任务结果中保留来源模版、运行参数和数据边界。

#### Scenario: 查看任务结果来源

- **WHEN** 用户打开模版任务结果
- **THEN** 页面可查看来源模版名称、活动、波次、关键参数和能力
- **AND** 可从任务返回模版详情
- **AND** 后续编辑模版不改变该任务的历史结果

### Requirement: 响应式与无障碍

任务模版库、创建流程、参数表单和结果 SHALL 支持桌面与窄视口，并具备完整键盘语义。

#### Scenario: 键盘创建与运行

- **WHEN** 用户只使用键盘
- **THEN** 可完成模版筛选、创建步骤、变量配置、产出选择、保存和发起任务
- **AND** 焦点不会进入隐藏步骤或已关闭弹窗
- **AND** 错误提示与对应字段建立可访问关联

## MODIFIED Requirements

### Requirement: 新建策略对话内置分析模版

现有“内置分析模版” SHALL 继续提供按促前、促中、复盘筛选和填入对话的能力，同时为可运行的任务模版提供详情和发起任务入口。

#### Scenario: 继续填入对话

- **WHEN** 用户在新建策略对话中点击“使用模版”
- **THEN** 现有活动、波次和问题文本继续只填入输入框
- **AND** 不自动发送
- **AND** 不创建任务实例

#### Scenario: 从详情发起任务

- **WHEN** 用户在模版详情选择“发起任务”
- **THEN** 系统打开结构化参数表单
- **AND** 不把参数表单内容直接拼接进输入框

### Requirement: 模版详情

模版详情 SHALL 从“描述 + 固定问题”扩展为“场景 + 参数 + 预期产出 + 所需能力 + 可折叠任务指令”。

#### Scenario: 查看可运行模版

- **WHEN** 用户打开任一任务模版详情
- **THEN** 首屏优先展示业务场景、必要输入和任务产出
- **AND** 技术性指令与能力细节位于下钻区域
- **AND** 页面不展示 Revision、Mock/真实数据等技术提示

### Requirement: 技能选择

任务模版运行 SHALL 复用现有技能目录和启用状态，但默认由模版能力标签推荐，不要求普通用户逐个选择技能。

#### Scenario: 高级用户调整能力

- **WHEN** 用户展开“执行能力”
- **THEN** 可查看模版推荐能力和实际映射技能
- **AND** 可调整非必需能力
- **AND** 系统预置与必需能力不能被无提示移除

## REMOVED Requirements

无。

## Out of Scope

- 真实后端模版存储、多人实时协作和跨设备持久化。
- 全局公开模版市场、收藏、评分、使用次数和运营推荐。
- 模版导入、跨空间迁移和分享链接发起。
- 批量任务、闲时队列和配额管理。
- 定时任务配置与飞书群自动投递。
- 真实 AI 参数提取；Demo 仅对内置示例或花括号变量进行确定性处理。
- 真实技能执行、数据查询和实验平台调用。
- 自动写入营销引擎、发券、预算、人群或渠道配置。
