# 验收清单

## 产品对象与入口

- [x] 工作区提供独立“任务模版”入口，与“新建策略对话”和“技能”职责区分清楚。
- [x] 新建策略对话中的“内置分析模版”继续作为快速提问入口。
- [ ] 提问模版只填入对话，任务模版运行会创建独立任务实例。
- [x] 任务模版保存任务指令、变量、产出契约和能力标签，不保存单次运行结果。
- [x] 技能作为可复用能力被模版引用，不因创建模版而复制或改写技能。

## 模版库

- [x] 模版库提供“全部 / 内置 / 我创建的”来源筛选。
- [x] 模版库支持促前、促中、复盘阶段筛选。
- [x] 模版库支持按名称或场景搜索。
- [x] 卡片只展示阶段、名称、场景说明和产出类型。
- [x] 页面不展示使用次数、收藏数、Revision、Mock/真实数据等无关信息。
- [x] “新建任务模版”入口清晰可见。
- [x] 新建策略对话模版区提供“查看全部”和“新建任务模版”入口。

## 创建路径

- [x] 用户可从模版库从零创建任务模版。
- [ ] 已完成且形成结构化产物的策略对话提供“沉淀为任务模版”。
- [ ] 从对话沉淀时预填任务目标、变量候选、能力和产出章节。
- [ ] 对话沉淀结果先进入草稿，用户确认前不保存或启用。
- [ ] 创建模版不会修改原对话、原策略产物或原活动上下文。

## 第一步：任务指令与变量

- [x] 创建流程第一步可编辑完整任务指令。
- [x] `{变量}` 能自动生成同名变量。
- [ ] 选中指令文本后可将其设为变量。
- [ ] 删除变量后不残留失效占位符。
- [x] 支持单行文本、数值、单选、日期/日期范围、链接、文件、活动上下文和波次上下文类型。
- [x] 每个变量可配置展示名、变量键、类型、说明、默认值、必填和上下文来源。
- [ ] 重复变量键、空变量键和未配置占位符有就地错误。
- [ ] 指令为空或变量配置无效时不能进入下一步。
- [ ] 撤销或删除变量不会破坏其他已配置变量。

## 第一步：任务产出

- [x] 创建者必须选择调优方案、分析报告、复盘结论或飞书播报摘要之一。
- [x] 调优方案默认包含决策摘要、调优动作、效果预估、证据、风险和待确认项。
- [ ] 创建者可选择方案对比、当前信号、配置快照等附加章节。
- [ ] 模版详情和运行摘要均展示预期产出结构。
- [ ] 效果预估区分可计算值、方向判断和缺失数据。
- [ ] 缺少数据时不会生成虚构的精确 GMV、ROI、预算或补贴结果。

## 第一步：执行能力

- [ ] 系统可根据任务指令和产出章节推荐业务能力标签。
- [x] 能力以中文业务名称展示，不要求用户理解内部技能 ID。
- [x] 用户可调整非必需能力。
- [x] 模版只保存能力标签，运行时解析当前可用技能。
- [ ] 必需能力停用、缺失或无权限时，运行前展示明确原因。
- [ ] 影响核心结论的能力不可用时阻止运行。
- [ ] 只影响可选章节的能力不可用时，可移除对应章节后继续。

## 第二步：基本信息

- [x] 系统可根据第一步起草名称、简介、阶段和场景标签。
- [x] 用户可以修改所有起草内容。
- [x] 可见范围仅提供“仅自己”和“当前工作区”。
- [x] 支持保存为草稿或保存并启用。
- [ ] 必填基本信息不完整时不能保存。
- [x] 保存后模版立即出现在“我创建的”。
- [x] 保存结果可直接查看详情或发起任务。

## 模版详情与管理

- [ ] 详情按场景、参数、预期产出、能力状态和折叠任务指令组织。
- [x] 首屏不堆叠完整 Prompt、技能技术说明或内部元数据。
- [x] 内置模版只读且可发起任务。
- [ ] 自建模版支持编辑、复制、启用和停用。
- [ ] 停用模版不能发起新任务，但历史任务仍可查看。
- [ ] 编辑已启用模版不会改写历史任务的参数和结果。
- [ ] 界面不展示技术性 Revision 文案。

## 发起任务

- [ ] 模版详情同时区分“填入对话”和“发起任务”。
- [ ] “填入对话”保持原有只填入、不发送、不创建任务的行为。
- [x] “发起任务”打开结构化参数表单，不把参数拼成可见长 Prompt。
- [x] 当前活动和波次可自动带入，并标明来自当前上下文。
- [x] 自动带入的活动和波次允许修改为其他有效选项。
- [x] 必填项为空、格式错误或上下文无效时就地提示。
- [x] 校验失败时不创建任务实例。
- [x] 提交前展示模版、活动、波次、关键参数、能力和预期产出摘要。
- [ ] 提交成功后每次生成新的任务实例。
- [ ] 任务实例固定当次模版、参数、上下文和能力快照。

## 调优策略场景与产出

- [ ] 4 个促前场景分别定义目标区间、券档矩阵、人群策略或渠道预算类产出。
- [ ] 5 个促中场景分别定义预算调优、目标冲刺、类目客单、面额门槛或竞对响应类产出。
- [ ] 2 个复盘场景分别定义钱效归因和下一轮策略沉淀类产出。
- [ ] 每个模版的产出与对应调优问题一致，不使用同一套泛化报告替代。
- [ ] 调优产出至少包含决策、动作、依据、效果边界和风险。
- [ ] 涉及线上配置的结果只生成待确认草案，不直接执行。

## 末波次预算紧张 Demo

- [x] 内置“末波次预算紧张调优”任务模版存在且可运行。
- [x] 默认变量包含活动、波次、`7200 万`覆盖容量、V1/V15、是否保量和风险偏好。
- [x] 默认能力包含指标口径、预算归因、异常检测和实验分析。
- [ ] 运行结果复用 V1/V15 `6.32 / 6.24`兑换比数据。
- [ ] 运行结果展示 L4、L5、jp/t8 `6.02 / 6.08 / 6.01`同位兑换比。
- [ ] 运行结果展示 jp/t8 `6,400 万`与大盘 L4-L5 `8,000 万`规模差异。
- [ ] 结果明确指出 V15 总增量偏低主要是量级效应。
- [ ] 推荐方案为大盘 L1-L5 按预期增量排序后由算法覆盖。
- [ ] 保量备选为 jp/t8 保底加剩余预算算法分配。
- [ ] `7200 万`覆盖容量对大盘 L4-L5 的覆盖率正确计算为 `90%`。
- [ ] 精确 GMV、ROI 和补贴额因数据不足而明确标记不可计算。
- [ ] 结果展示算法挤占、显著性、样本稳定性、单人成本和库存等风险。
- [ ] 结果生成待确认配置快照，不触发任何线上配置。

## 来源追溯

- [ ] 任务结果展示来源模版名称。
- [ ] 任务结果展示活动、波次和关键参数。
- [ ] 任务结果展示使用的能力和数据边界。
- [ ] 可从任务结果返回来源模版详情。
- [ ] 后续修改模版不改变历史任务结果。
- [ ] 从任务继续追问会创建新消息或新结果，不改写原产物。

## 视觉与响应式

- [ ] 模版库、创建弹窗、参数表单和结果复用现有视觉 Token。
- [ ] 核心场景、参数和产出优先展示，技术指令与能力详情按需下钻。
- [ ] 1280px 和 1024px 下创建第一步可清晰展示指令与变量配置。
- [ ] 760px 下双栏创建布局转为单列且步骤顺序正确。
- [ ] 390px 下字段、筛选、底部操作和结果卡片不超出视口。
- [ ] 所有视口下无页面级横向溢出。
- [ ] 长模版名称、变量说明和产出章节可完整查看。

## 键盘与无障碍

- [ ] Tab 可访问模版入口、筛选、搜索、卡片和创建按钮。
- [ ] Enter/Space 可激活页签、筛选、卡片、步骤和选择控件。
- [ ] Escape 可关闭创建、详情和运行弹窗。
- [ ] 弹窗打开后焦点进入弹窗，关闭后返回原触发控件。
- [x] 不可见步骤和折叠区域不会接收焦点。
- [ ] 字段错误与对应输入通过可访问描述关联。
- [ ] 变量必填、技能不可用和模版停用状态具备可访问语义。
- [ ] 动态新增或删除变量后焦点位置合理且状态可感知。

- [ ] 现有模版详情、复制和快速填入保持正常。

- [ ] 技能搜索、选择、系统预置锁定和技能管理跳转保持正常。

- [ ] 促前、促中工作台和两个历史案例保持正常。
- [x] 用户当前未提交的历史归档改动未被回滚或覆盖。
