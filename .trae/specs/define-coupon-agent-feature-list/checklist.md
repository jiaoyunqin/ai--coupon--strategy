# 验收清单

## 功能完整性

- [x] Feature List 覆盖策略决策闭环、任务自动化、能力资产管理、协作与治理四个领域。
- [x] 新建策略对话、创建定时任务、知识库管理、技能管理、分析模版管理均作为独立一级功能。
- [x] 促前规划、促中调优和活动复盘的职责边界清晰。
- [x] 历史对话、策略报告和版本追溯有统一归属。
- [x] 数据源、模型、MCP 和飞书协作没有遗漏。
- [x] 工作区权限、安全治理和线上执行边界有明确归属。

## 优先级

- [x] 每个一级功能均标记 `P0` 或 `P1`。
- [x] P0 能形成“提出问题 → 获取策略 → 形成产物 → 自动跟进 → 沉淀复用”的基础闭环。
- [x] P1 只承载基础闭环之外的复盘、集成和协作增强能力。
- [x] 功能优先级不依赖尚未确认的复杂技术方案。

## 产品边界

- [x] 每个一级功能都有明确的核心子能力。
- [x] 对话、模版、任务、定时任务之间的关系可解释且不重复。
- [x] 知识库、数据源、技能、模型和 MCP 的资产职责相互区分。
- [x] 所有线上发券、预算、人群或渠道变更默认需要确认或审批。
- [x] 本规格未提前扩张到字段级交互、接口、算法或数据库设计。

## 后续可执行性

- [x] 每个新增需求都能映射到一个主要一级功能。
- [x] 跨功能需求能够识别主功能、依赖功能和数据流向。
- [x] P0 功能可继续拆分为独立、可验收的详细规格。
- [x] 现有产品能力可按“已有基础 / 待补齐 / 未建设”进行映射。
